# OniGame v0.40.45

- 堕狐「狐渡り」を強化。射程30（心臓破壊で段階低下）、CT16秒基準、終了後Speed II 3秒。
- 狐渡りの移動線上に青白い狐火＋煙の軌跡を生成。軌跡は35tick残留し、同一対象は1回の狐渡りにつき1回だけ4.0固定ダメージ＋短時間炎上。
- 自動アリーナ配置のプレイヤー/鬼スポーンに最大Y制限を追加。上限以下を下方向探索し、葉・液体・危険な空間を避ける。
- `/og automap maxy [Y]` で確認・変更。設定は `arena-setup.spawn-max-y` に保存（既定90）。
- 心臓・出口等の高度にはこの上限を適用せず、開始スポーンだけが対象。

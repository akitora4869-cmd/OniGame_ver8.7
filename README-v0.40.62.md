# OniGame v0.40.62

## TAG SP shop diversity
- TAG SP shops are randomized globally at match start instead of independently.
- A product is removed from the shared draw deck after assignment, so another shop cannot sell it until the whole product pool has been distributed once.
- If there are more shop slots than unique products, duplicates are allowed only after a full pool cycle, while avoiding immediately copying the previous shop lineup.
- Each shop receives four distinct products for a clearer identity.
- The lineup remains fixed during the match and is rerolled on the next TAG match.

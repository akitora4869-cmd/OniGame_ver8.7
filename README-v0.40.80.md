# OniGame v0.40.80 - PV Shooting Mode

PV撮影専用モードを追加。

- `/og mode pv` / `/og pv start` / `/og pv stop`
- 自動Bot補充なし、試合タイマー・勝敗・自動フェーズ進行なし
- `/og pv actor <player> <player|oni>` で役者化
- `/og pv bot <player|oni|clear> [oniType]` で必要なBotだけ召喚
- `/og pv time <day|noon|sunset|night|midnight>`
- `/og pv weather <clear|rain|thunder>`
- `/og pv freeze|unfreeze` で役者とBotを静止（非参加の撮影者は移動可能）
- `/og pv heal`
- `/og pv effect <hyakki|final|clear>`
- TAGショップ/Terra宝石はPVでは非表示

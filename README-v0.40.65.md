# OniGame v0.40.65 - Terra Escape Gates

## Terra objective
- Four gems charge each player's talisman to 4/4.
- Three escape gates can be registered per Terra map.
- Gates open automatically when 5:00 remains.
- Gate opening uses a large portal-style announcement, sound and particles.
- Superseded by v0.40.66: a player with 4/4 power escapes by sneaking for 5 seconds within about 5 blocks of an opened gate.
- Players without 4/4 power or players away from a gate cannot escape.

## Commands
- `/og tag terra gate add` - register current position as the next gate (max 3)
- `/og tag terra gate list`
- `/og tag terra gate clear`
- `/og tag terra status`

The TAG player UI still does not reveal the match countdown; the gate-opening event itself tells players that the final escape window has begun.

# OniGame v0.40.61 — TAG Stock Lives

- TAG通常プレイヤーは残機1、配信者モードは残機2。
- 致死ダメージ時、残機があれば死亡せず残機を1消費し、HP全回復・完全透明化・高速移動で緊急離脱。
- 残機0で次にHP0になると復活アスレチックへ移動。
- アスレチックをクリアすると残機を最大値まで再補充（通常1 / 配信者2）。
- 最終フェーズでは新規の残機消費・アスレチック復活を行わない。最終突入時に既に挑戦中のプレイヤーは従来どおりその1回を継続可能。
- `/og tag streamer <player|me> <on|off>` で配信者モードを設定。`/og tag streamer list` で確認。

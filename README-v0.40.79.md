# OniGame v0.40.79 - TAG Global Resonance

Terra鬼ごっこに、参加者全体の宝石スキルチェック結果が試合へ影響する全体連動イベントを追加。

- 霊脈共鳴: GREAT蓄積で30秒間同調加速 + 参加者にSP
- 鬼気増幅: 失敗蓄積で30秒間鬼を小強化
- 完全共鳴: 12秒以内のGREAT連鎖で、現在同調中の宝石進行を一斉加速
- 禍津共鳴: 12秒以内の失敗連鎖で怪異演出、鬼へ該当宝石の方角を通知
- 生存共鳴: 百鬼夜行終了時、人間参加者の65%以上が生存していれば全体SPボーナス
- 通常の蓄積は実参加人数に応じて閾値を自動調整
- Bot由来の通常蓄積寄与は0.5
- 共鳴系には45秒の共通クールタイム
- 残り5分の脱出フェーズでは新規蓄積を停止

# OniGame v0.40.54 - Tag Skill VFX

鬼ごっこ(TAG)モード専用のプレイヤースキル演出を追加。

- 通常モードのスキル演出は変更しない。
- TAG時のみ、疾走・隠形・煙幕・破鬼撃・治療・執念・瞬歩・残響・霊視・不退転・封鬼陣・共鳴・身代わり・決死行・武芸に専用VFX/SEを追加。
- 疾走、不退転、決死行は短時間の走行トレイルを追加。
- 瞬歩は発動地点に加えて到着地点にもリング/風圧演出を追加。
- 20人超を想定し、長時間大量に残る粒子ではなく短時間・高密度を中心にしている。
- 安定着地はTAGでは落下ダメージ無効のため専用発動VFX対象外。

Note: この生成環境には Maven がないためコンパイル未実行。GitHub Actions等でビルド確認してください。

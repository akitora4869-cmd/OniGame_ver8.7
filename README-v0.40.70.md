# OniGame v0.40.70 - Unei Tag

- Added persistent scoreboard tag `unei`.
- `unei` players are excluded from normal game participation, player counts, oni selection and bot-fill human counts.
- `unei` includes `map_maker`. `/og unei add` grants map_maker and tracks whether it was granted by unei.
- `/og unei play` opts an unei player into the next single match while retaining unei/map_maker. The override is cleared after the match.
- Commands: `/og unei add <player>`, `remove`, `list`, `status [player]`, `play [player]`.

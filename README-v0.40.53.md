# OniGame v0.40.53 - Chase Sound-Only Feedback

- 通常モード・鬼ごっこモード共通で、チェイス開始時の「見つかった」「逃げろ」TITLEを廃止。
- チェイス解除時の「追跡から逃れた」「息を潜めろ……」TITLEを廃止。
- 人間鬼側の「獲物を発見: <player>」ActionBarも廃止し、チェイス情報を文字で直接通知しないよう変更。
- 発見時はSCULK SHRIEKER系SE＋既存追跡BGM開始、撒いた時はAMETHYST系解除SE＋既存追跡BGM停止/フェード処理で認識する。
- 発見時の短いDARKNESS演出は視覚演出として維持。

# OniGame v0.40.63 - Terra Gems

TAG map `Terra` objective foundation.

- Four personal objective gems: diamond, gold, emerald, lapis lazuli.
- Register by looking at the matching block and using `/og tag terra gem <diamond|gold|emerald|lapis>`.
- `/og tag terra status` reports registration state.
- Each registered gem continuously emits a color-matched orbit / rising-light particle effect during TAG.
- Every player can collect each gem once per match. Collection is personal; the physical gem remains for other players.
- Each gem grants +1 spirit power and +2 earned SP.
- Players receive a Terra talisman showing 0/4 through 4/4 spirit power; it upgrades to `力の込められたお札` at 4/4.
- Collection plays a matching transfer/charge VFX and completion effect.
- Match reset clears all personal gem progress.

The three-gate / remaining-five-minutes escape stage is intentionally left for the next Terra objective step.

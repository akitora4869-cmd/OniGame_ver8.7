# OniGame v0.40.78 - Terra Gem Traits

Terraの4宝石に固有の攻略特性を追加。

- ダイヤ: 標準型。従来の同調テンポと判定幅。
- 金: 通常/GREAT判定が狭い。GREAT成功時の進行ボーナスを大幅増加。
- エメラルド: 判定は標準型だが、同調中は宝石上空に緑色の光柱が発生し、鬼側から位置を察知されやすい。
- ラピスラズリ: スキルチェック発生頻度が高い。判定幅は広め、失敗時の進行減少は半分程度、1回ごとの成功/GREATボーナスは控えめ。
- 同調開始時、本人のチャットに宝石の特性を表示。
- TAGプレイヤーBotの宝石攻略にも同じ方向性の個性を反映。
- 既存の個人進行、中断時75%保持、霊力4/4、SP報酬、ゲート脱出仕様は維持。

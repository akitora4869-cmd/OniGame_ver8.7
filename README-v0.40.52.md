# OniGame v0.40.52 - Tag PlayerBot AI

- `game-mode: tag` / `/og mode tag` を追加。
- 鬼ごっこモードではぷれいやー陣営を `tag-mode.player-count`（標準20）までBot補充。
- 鬼ごっこBotの最大体力は10。
- 通常モードの心臓作業AIから分離し、鬼接近時は逃走、非チェイス時は未訪問の物資チェスト探索、物資がない場合は周辺徘徊。
- Botごとに訪問済みチェストを保持し、同じチェストへの往復を抑制。
- 通常/DUO/ESCAPEの既存Bot AIは変更しない。

※ 鬼ごっこモード全体（神社開始、遅延鬼出現、SPショップ等）は引き続き個別実装対象。本版はPlayerBot AIのモード分離・大人数補充の基盤。

# OniGame v0.40.48

## 自動配置安全化
- `/og automap maxy` をスポーン・心臓・出口・自動チェスト・追加支援・異獣の自動配置判定に共通利用。
- HeightMapの地表のみを候補にし、水中/液体、葉、危険地面、閉鎖地下候補、ロビー領域を除外。
- 最低3ブロックの地盤厚を要求し、薄い空中床/空中テストロビーを除外。
- 安全地点が見つからない場合は無理に洞窟等へフォールバックしない。

## 異獣貢献度報酬
- ラストアタック独占を廃止。
- 与ダメージを主軸、異獣から受けたダメージをタンク貢献として加点、ラストヒットは小ボーナス。
- 原則10%以上、または絶対貢献8pt以上で報酬対象。
- 条件を満たした人間プレイヤーには各自インベントリへ加護を付与。Botは従来通り保持して必要時に使用。
- 各値は config.yml の `ikimono.contribution` で調整可能。

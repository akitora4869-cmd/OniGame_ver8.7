# OniGame v0.40.67 - TAG Final Timer

- In TAG mode, the oni sidebar now shows the remaining match timer for the entire match.
- Player-side TAG sidebars still hide the timer during the normal phase.
- At 5:00 remaining, when Terra escape gates open, the remaining timer becomes visible to players as well.
- The countdown continues visibly from 5:00 to 0:00 during the escape phase.
